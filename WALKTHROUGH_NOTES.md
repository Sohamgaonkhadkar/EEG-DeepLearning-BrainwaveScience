# Live walkthrough notes

- **Task:** T1 both fists versus T2 both feet in imagery runs 6/10/14; neither left/right imagery nor executed runs 5/9/13. This is a medial-versus-lateral/anterior-posterior spatial contrast, not simply hemispheric lateralization.
- **Defects:** Show initial commit b76b586 and the six separate correction commits. Trial test leakage and trial validation leakage are two independently corrected split paths. Direction of a particular accuracy change cannot be inferred without isolating it experimentally.
- **Independence:** Optimize on people 1-6, choose checkpoints on people 7-8, then evaluate 9-10. Fit per-channel scaling on 1-6. Audit sample hashes and channel order. All seeds, models, windows, and hyperparameters are declared before test evaluation; no seed is selected for reporting.
- **Mu/beta ERD:** Band-pass continuous data, square Hilbert amplitude, average power over trials, then compute 100*(P-P_rest)/P_rest against -1.5 to -0.5 s. Negative is desynchronization; beta uses 13-30 Hz and mu uses 8-13 Hz. Acausal filtering can smear transitions, so interpretation is offline and the baseline avoids the immediate cue.
- **C3/C4/Cz:** C3/C4 sample lateral sensorimotor areas; Cz samples near the medial foot representation. Bilateral fists can affect both hemispheres. Scalp EEG mixes sources; reference, anatomy, trial variability and cue/ocular activity can weaken simple somatotopy.
- **Cue confound:** Top/bottom gaze changes can produce vertical ocular potentials, especially frontally; classification from frontal sensors alone cannot establish their source. Randomize/counterbalance cue location independently of class and record eye position/EOG; use a delayed central instruction and gaze control.
- **EEGNet:** Temporal kernels learn band-related filters; depthwise electrode kernels learn D spatial combinations for each temporal feature, with no mixing between F1 groups. Separable convolutions and pooling constrain capacity and provide local structure useful with few people.
- **Attention:** softmax(QK^T/sqrt(d_k))V. Independent unit-variance dot products have variance d_k; dividing by sqrt(d_k) controls scale and avoids saturated softmax and small gradients.
- **Actual sizes:** With 481 samples, vanilla has 482 tokens including CLS and each head has a 482x482 score matrix. Padded patches of 32 samples give ceil(481/32)=16 tokens plus CLS, hence 17x17. There are four heads, three layers, d_model=64, d_k=16, feedforward width=128, dropout=0.3. The score-count ratio is 232324/289=803.89, not a promise of equal wall-clock speedup.
- **Single bet:** Learned 200 ms temporal aggregation via Conv1d(kernel=stride=32) before attention. The starter already provided this idea; the contribution is validation, preserving the last sample through right padding and conducting the controlled comparison, not claiming invention. Patching increases the input projection parameter count and may alias or discard phase details.
- **Evidence:** Read the actual generated tables and figures in ANSWERS.md. Report all three seeds, best/worst, population SD, and the two individual test-subject accuracies. Neither a lucky run nor t-SNE separation proves generalization; three seeds are not three independent populations.
- **Attention interpretation:** No claim about where attention focuses is made without extracting maps and checking against controls. An attention weight alone is not a causal explanation.
- **80 subjects:** More subject diversity could help vanilla attention learn shared structure; patching would still reduce computation but its generalization benefit must be retested. Compare learning curves, matched parameter budgets, multiple subject folds and a separately collected final test set.
